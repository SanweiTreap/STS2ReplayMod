# UI-002 原生历史记录观看入口

2026-11-08。目标版本 v0.111.0。接续 build-071 工作树及现有实现对话。

## 玩家流程

从「百科大全 → 历史记录」找到一条单人对局。「观看回放」在原生「分享」左侧，沿用它的视觉语言。左右翻历史时根据当前条目刷新。缺少可播放录像的条目采用原生式禁用。点击后从现有整局观看流程开播；观看中的原生菜单提供「退出回放」，替代普通对局的「保存并退出」和「放弃」，安全收尾后回到刚才的历史条目。

## 实施

- 先读固定版 `NRunHistory.DisplayRun`、`NShareButton`、原生历史保存调用和回放启动／Stop 的实际调用方。复用现有播放器和安全退出。普通模式的菜单与历史行为照常，开发入口可继续用于复测。
- 建立或复用按当前 profile 与原生历史持久身份查询 Replay RunId 的关系。可核对现有 `BattleRecording.RunStartTime`、战前存档和真实历史是否同源，以复用有可靠关联的旧录像。同种子、列表序号和近似时间不能代替身份。旧片无法可靠关联时显示禁用，并沿原生历史保存路径让新录制可关联。翻历史只做轻量查询，点播放再读目标录像。
- 源页面选择以历史身份恢复，覆盖原场景已被替换的情况。退出走已有 teardown，成功后再恢复历史页面。范围到观看、禁用和退出；收藏、卡册、设置细项、跳转另列。

## 交付与短测

实现、构建、修复本包内 bug 可在同一对话连续推进。沿现有备份和安装流程准备候选，用户操作游戏，不用 Computer Use。优先找已有的一条匹配录像和一条无录像历史，做一次短流程：左右切换确认启用状态 → 从正确历史开播并前进一步 → 原生菜单退出 → 回到同一条历史。若已有文件没有可靠关联，再说明并准备最短的新录制样本。交回候选版本、可直接执行的用户步骤，以及已验证和仍待人工验证的结果。

RUN-005 另需用现有 235 项三幕录像从涅奥连续观看到胜利详情后退出。先推进本包代码，等用户方便时安排整局验收。若这条录像能从新历史入口打开，可合并两项测试，仍分别记录结果。
