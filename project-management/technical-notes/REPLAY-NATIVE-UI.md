1. 观看控制：进度条/按钮位置、常驻或按需展开；不遮手牌/敌人意图/选择页，区分当前位置、排队与等待/恢复反馈。已有D-131动作语义不重新发明。
2. 导航层级：当前房间/战斗操作轴与整局路线图分别表达；普通Back/>/>>与未来下一回合/下一房间入口如何组合，显示进度与点击/拖动Seek分开定义。最终目标包含未访问/跨房间定位，但当前仅已有合法起点/已访问稳定点获证，不能因画了进度条就冒充任意Seek实现。
3. 模式/节奏设置：入口、三种合法组合、修改何时生效、与Auto/当前队列关系、倍率范围、旧片缺过程/时间的呈现。
4. 管理/编辑细节：目录与分类、导入/导出、改名、移除与取消收藏/删除的区别、卡面编辑预览；固定章位具体排布/上限留视觉草图比较，不再逐条讨论所有数值。
5. 文件/边界：独立存储与清理策略、未完/缺口/不兼容录像反馈、Stop返回观看来源；PNG技术验证在后续阶段，不作当前卡面前置。

观看栏的“紧凑信息/入口常驻，详细控制按需展开”是PM待讨论候选，尚未用户确认；具体布局与快捷键未定。本次不新增控制代码、完整时间轴或原始输入采集任务。
